# COURT // 1V1

A browser-based basketball one-on-one game.

```sh
cd /Users/test/Projects/basketball-1v1
python3 -m http.server 4183
```

Open http://localhost:4183.

## Controls

- **A / D:** Move
- **W:** Jump or block
- **S:** Hold to charge and release to shoot
- **Space:** Start/restart the game
